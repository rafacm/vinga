### Fixed

- **A generation's exported content is counted only once its `llm` span took it** (#588). With `server.telemetry.export_llm_input` on, a round's request and output were counted in `llm_input_exported`'s `rounds` as soon as they were staged, before the `llm_round` or `provider_failed` event that writes them onto the span was emitted. When that event could not be built, the count claimed a pair no span received, the staged content stayed in memory until the server shut down, and nothing reported the loss. A generation now follows the contract a tool call's content already had: the round's event is emitted exactly once, the pair is counted only after its fold attached it, and a pair the event never delivered is released at once and reported as `llm_input_export_failed` with `kind: generation`. A round the first-token watchdog retried still counts as one round. With the export off nothing changes.
