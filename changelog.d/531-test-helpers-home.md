### Changed

- The tests' secret-absence checks about exceptions now walk a refusal one way, and that walk reads more than any of them did (#531). Fifteen suites carried their own copy of a walk that read an exception's `repr` and `str` alone, while a stronger one a directory away also read its arguments and two levels of its attributes. Every suite now uses one walk in `vinga-server/tests/support/leaks.py`, which also reads each argument's `str`, attribute names as well as their values, and an exception's `__context__` when it has a `__cause__` as well, a link every copy used to skip. Each of those readings is pinned in `vinga-server/tests/unit/test_support_leaks.py`, since no suite that relies on the walk could fail if it weakened. Alongside it, test helpers that were copied between suites now have one home each: the Alembic driver the upgrade tests use (`tests/support/migrations.py`), the OpenAI SDK client the speech-provider tests build (`tests/support/openai_sdk.py`), and the test waveform, the stdio MCP entries, the CLI capture reading and the scripted model's tool-result reads, which already had a home in `tests/support` and were copied anyway. No server behavior changes.
