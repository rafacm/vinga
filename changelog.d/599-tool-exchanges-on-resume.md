### Changed

- **A resumed conversation now carries its tool exchanges** (#599). Resuming a thread used to rebuild only what was said, with `(tools used: <names>)` appended to a reply that had run tools; it now rebuilds every call each turn kept, with its arguments and its result, from the conversation store, round by round and with server-minted ids, the same calls the session itself kept: a call that had its result, a malformed one with no arguments beside its error, and not a call still running when its reply was cut nor a move that handed the conversation on. Every request on the resumed thread then clears results over 2 KiB and turns calls to tools it no longer offers into the plain-text record, exactly as for a conversation that never ended. The exchanges count against the resumption budget, each at the size of its plain-text record with a result over 2 KiB counted as its cleared note and every character outside ASCII counted as its JSON escape, which is never less than what a request sends, so a thread whose agent used tools is read less far back than before. A consented recap reads the exchanges too, every call as the plain-text record, since the summarizing request offers no tools. Rows stored before this change are read the same way and need no migration. A deployment that stores no conversation text cannot resume and is unaffected.
- **Anthropic requests also join consecutive assistant turns into one message** (#599). A past call to a tool no longer offered is sent as a plain-text record in the assistant's turn, so on a resumed thread, or after an MCP reload, that record can be followed by another assistant turn: the reply that was spoken after the call, or a later call that is still offered. The Anthropic translator now appends a plain assistant turn to the assistant message before it as a text block, and a turn that calls tools takes the earlier message's text as its leading blocks, so the roles alternate as that API requires. The history itself keeps its turns as they were; OpenAI-compatible requests are unchanged.
