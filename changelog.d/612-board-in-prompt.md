### Changed

- **vinga knows the board it speaks through** (#612). The built-in agent's prompt now carries the facts of the device's guide, its opening and its Controls section, chosen by the board model the device reported at its OTA check-in: a board running the upstream firmware reports it each time it starts (the Waveshare ESP32-S3-Touch-LCD-1.54 as `esp32-s3-touch-lcd-1.54`), and the browser page each time it loads, as `vinga-browser`. A board with no guide, or one that has not checked in since the server started, gets a fixed note saying the server has not been told which board it is instead, and vinga then declines device questions rather than guessing and points to the device's guide; restarting the device teaches it. The reported string is only used to choose a guide and never reaches a prompt, and no other agent's prompt changes.
