### Added

- **Choosing the model an agent thinks with has a task guide of its own** (#364). `docs/run/llm.md`, listed under Configuring in `docs/run/README.md` and linked from Getting Started's step 0 and from `providers.md`, is the LLM stage's guide: what a model has to do for a voice agent (make real tool calls, answer inside `llm_first_token_timeout_s`, fit the machine) and how to check each; the local preset's `qwen3:8b` beside Getting Started's `llama3.1:8b`, with their measurements and dates; switching by replacing the entry agents already use, or by exporting, editing and setting the agent or `agent_defaults` so nothing else on it is lost; reaching a runner on the host from the container, with a check run from inside it; recipes for Ollama, llama.cpp, Anthropic and OpenAI, and the addresses of LM Studio, vLLM, Groq, OpenRouter and Together; widening the data boundary deliberately before a vendor; and the two places a key goes without ever being part of a command. It also writes down three things nothing said before: raising `llm_first_token_timeout_s` past 30 seconds buys nothing, since the request itself gives up after 30 seconds without a byte; `qwen3:8b` on Ollama streams its thinking before it answers, which keeps the watchdog quiet while the device waits, unless the entry carries `reasoning_effort: none`; and an apply refused for an entry leaves the write stored, so the next start refuses with the same sentence until the write is put back.
