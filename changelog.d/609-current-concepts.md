### Changed

- **The concepts page and the glossary describe only what runs today** (#609). `docs/concepts.md` no longer calls itself ahead of the code: its per-section status lines, its issue references and its decided-direction passages are gone, the help-agent section is removed (vinga's own built-in agent is #612), "Before users arrive" is now "Who the user is", and Meta capabilities describes the three built-in tools that exist. The glossary drops its issue references and its planned Help agent entry, and gains a **Coding agent** entry separating vinga's agents from the programs a person runs to work on a deployment or the code. Direction that an issue owns stays in that issue; the seven decisions nothing owned, among them changing a device's default agent by voice and per-conversation cost, are recorded with their dates on a new Develop-door page, `docs/architecture/direction.md`. The Touch-LCD-1.54 board guide states its firmware limits (no prebuilt image carries the English wake word; the interface language is compiled in) without promising a vinga firmware build.
- **Run and Use pages are checked for issue references and planned direction.** `scripts/check_run_use_pages.py` reads the Run vinga and Use vinga sections of `docs/README.md` and fails when any page they link carries an issue or pull request reference or the phrase "decided direction"; it runs in both CI workflows, next to the link check and beside lint.
