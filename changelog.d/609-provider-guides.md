### Changed

- **Choosing providers, tools, memory and prompts has task guides of its own** (#609). Six more guides in `docs/run/`, listed under Configuring in `docs/run/README.md`, take that part of the server README: the table of provider types and what an install carries (`providers.md`), the transcription engines measured against each other and setting OpenAI's vocabulary and languages (`speech-recognition.md`), the voices and how long each keeps a device silent (`voices.md`), MCP servers, grants, guidance, the builtins and the status command (`tools-and-mcp.md`), what an agent remembers and `vinga memory` (`memory.md`), and the prompt preview and shared fragments (`agents-and-prompts.md`). The OpenAI transcription and ElevenLabs option tables are no longer repeated: the guides link their sections of `docs/reference/domain-config.md`, which is where those options and their defaults are generated from. The ElevenLabs voice listing, in `voices.md` and in the comment of `examples/tts-elevenlabs.yaml`, now hands curl the API key on standard input (`printf 'header = "xi-api-key: %s"\n' "$ELEVENLABS_API_KEY" | curl -s -K - ...`) rather than in its arguments, where the process table could show it. Seven statements the moved text made were wrong against the code and are corrected: `set_device_location` is a reserved MCP entry name and an always-offered builtin; an unset `$VAR` fails the boot only for an MCP entry some agent references; a value known to be a credential is redacted from what a server ships back whatever its length; a forgotten fact is held for as long as its conversation is kept; only an erasure through the API reports how much of a conversation's ledger went; and the prompt-echo check ignores any sentence-final punctuation.
