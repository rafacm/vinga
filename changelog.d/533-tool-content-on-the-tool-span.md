### Added

- **A `tool` span now carries what its call was asked and what it answered, when `export_llm_input` is on** (#533). The span carries the GenAI conventions' `gen_ai.tool.call.arguments` and `gen_ai.tool.call.result`, which Langfuse shows as the tool observation's input and output with no alias of vinga's. The arguments are what the model asked with, not the copy coerced to the tool's declared types for the far side, encoded exactly as the asking round's `tool_call` part on the `llm` span encodes them; a call that sent no JSON object carries its raw argument text. The result is the string the model was handed back. Off, nothing changes, and the `tool_call` event gains nothing either way. A tool call's pair has the same 256 KiB ceiling as a request, and one round's tool calls together have that ceiling too; a pair past either is dropped whole and reported. The bundled Collector masks email-shaped values in both new keys before either sink, like every other content field.

### Changed

- **`llm_input_exported` and `llm_input_export_failed` now say which kind of content pair they are about** (#533). `llm_input_export_failed` gains `kind`, one of `generation` (an `llm` span's request and output) or `tool_call` (a `tool` span's arguments and result), and `llm_input_exported` gains `tool_calls`, how many tool spans received a complete pair, beside `rounds`, whose meaning does not change. Both log templates change with them: `session %s: %d generation and %d tool call content pairs attached to telemetry` and `session %s: %s content pair not attached to telemetry (%s)`.
- **`export_llm_input` now says plainly that the household's remembered facts leave with it** (#533). Memory has no switch of its own: with the export on, the memory each round's request carries goes with every round, and the memory tools' arguments and results go on their tool spans. The backend keeps them by its own policy, and deleting or correcting a fact here reaches none of what already left. The setting's description, the example configuration and the observability page say so.
